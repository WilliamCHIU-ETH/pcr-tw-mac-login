# 公開範圍

本 repo與私人研究目錄分開建立，採明確檔案白名單，不從整個工作區直接git add或遞迴複製。

目前公開內容：README（含運作原理圖與輕量泳道圖）、去識別化方法文件、architecture.md 的三張Mermaid時序圖、合成JSON、授權查核摘要、逐函數來源分析、.gitignore、LICENSE與自寫的公開內容檢查器。

私人資料沒有刪除，而是完全不進入本 repo；也沒有用符號連結連回私人目錄。僅靠.gitignore不能清除既有Git歷史，因此這裡建立的是全新本機Git倉庫，沒有繼承私人資料的提交歷史。

## 檢查方式

```sh
python3 tools/check_public_tree.py
```

檢查器核對白名單、拒絕符號連結、檢查本機路徑與常見憑證樣式、驗證Markdown本機連結及合成JSON。掃描通過只證明這些檢查沒有發現問題，不是所有秘密或法律風險皆已排除。

## 發布與後續維護

此 repo 僅發布上述白名單內容，沒有繼承私人研究資料的 Git 歷史。檢查範圍包含實際提交清單，不能只依靠 .gitignore。

- 文件、圖表、合成範例與自寫檢查器以 Apache License 2.0 授權；不涵蓋上游原碼，也不宣稱是已授權的開源登入客戶端。
- 登入／解碼原型保持私有；來源對照見[程式來源分析](code-provenance.md)。
- 後續加入可執行工具前，另行處理來源及授權條件、移除私人相依性並測試。
- 發布操作不需要登入遊戲、存取憑證或改動 ADB／root。

本次沒有聯絡上游作者。GitHub 的實際提交與公開狀態以遠端倉庫為準。
